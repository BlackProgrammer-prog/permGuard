# Changelog

All notable user-visible changes are recorded here. The project follows Semantic Versioning after the initial pre-1.0 release.

## [Unreleased]

### Changed

- Completed release hardening and comprehensive user documentation.
- Added multi-version CI and npm trusted publishing automation.
- Added exact tarball verification and package provenance metadata.
- Made the CLI version derive from its package manifest.

## [0.1.0] - Unreleased

### Added

- CASL-based core, server, React, and Next.js integration packages.
- TypeScript Compiler API analyzer with Next.js Route Handler and Server Action discovery.
- Import-aware CASL definition, enforcement, and UI usage detection.
- fetch, Axios, Axios instance, ky, and custom API wrapper discovery.
- conservative authorization issues with severity and confidence.
- deterministic authorization graph and boundary coverage.
- CLI scan, graph, report, diff, and CI policy commands.
- self-contained offline HTML and JSON reports.
- semantic authorization diff and severity threshold evaluation.
