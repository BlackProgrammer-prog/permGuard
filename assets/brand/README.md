# IronPermJS brand assets

- `ironpermjs-banner.png` is the primary project artwork for repository and documentation headers.
- `ironpermjs-icon.png` is the compact mark for the GitHub organization or repository avatar, npm organization avatar, and social preview artwork.

Keep the original aspect ratio and sufficient padding around the shield. Do not stretch, recolor, crop through the mark, or place it on a background that reduces contrast.

GitHub and npm profile images must be uploaded through their respective account or repository settings; they cannot be configured from package metadata.
